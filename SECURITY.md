# Security

## Reporting a problem

**Found leaked secrets, credentials, or personal data in a report?** Open an
issue titled `TAKEDOWN:` or contact the repository owner directly through
their GitHub profile. It gets priority — we'll strip the content and rewrite
history if needed.

**Rights holder with a concern about a report?** Same channels. Reports are
original analysis for research and education; we don't publish binaries or
decompiled source, and we'll work with you on anything you find
objectionable.

## Out of scope

This repo contains analysis documents, not code. We don't publish exploits.
If you found a vulnerability *in* one of the analyzed apps, report it to the
app's vendor — then feel free to write it up as a report here.
